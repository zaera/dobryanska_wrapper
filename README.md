# Dobryanska Wrapper - Карта з 3D-моделями та адмін-панеллю

Цей проект представляє собою інтерактивну карту, що використовує Mapbox GL JS та Threebox для відображення 3D-моделей будівель. Проект включає функціонал перемикання видимості фонових об'єктів та базову адміністративну панель.

## Технології

*   **Mapbox GL JS**: Для відображення інтерактивних карт.
*   **Threebox**: Розширення для Three.js, інтегроване з Mapbox GL JS для рендерингу 3D-об'єктів.
*   **Three.js**: JavaScript бібліотека для створення та відображення 3D-графіки у веб-браузері.
*   **GLB Models**: Формат 3D-моделей (наприклад, `Town-Gradient.glb`).
*   **Material Symbols**: Для іконок користувацького інтерфейсу.

## Адмін-панель (`admin.html`)

Проект включає базову адмін-панель для управління. Доступ до адмін-панелі здійснюється через файл `admin.html`.

### Автентифікація

Адмін-панель використовує механізм автентифікації на основі хешованих логіна та пароля. Очікується, що хеші (`userHash` та `passHash`) будуть налаштовані в `config.js`.

**Важливе зауваження:** У поточній версії присутній **обхід авторизації** для зручності розробки, який автоматично надає доступ до адмін-панелі без введення облікових даних. **Для використання в робочому середовищі цей обхід необхідно видалити!**

Якщо ви хочете вимкнути обхід авторизації та використовувати повноцінну перевірку пароля:
1.  Перейдіть до файлу `admin.html`.
2.  Знайдіть рядки, позначені як `//BYPASS!!!!!!!!!!!!!!!!!` та видаліть їх, а також наступні за ними рядки коду, які встановлюють `sessionStorage.setItem('adminOK', '1')` та ініціалізують `initApp()`.
3.  Відредагуйте `config.js` та встановіть бажані `userHash` та `passHash` (це SHA-256 хеші).

Щоб згенерувати SHA-256 хеш для вашого логіна та пароля, ви можете тимчасово додати в `admin.html` (або виконати в консолі браузера на сторінці `admin.html` після завантаження) наступний код:

```javascript
// Приклад для генерації хешу
async function getMyHash(inputString) {
    const hash = await sha256Hex(inputString);
    console.log(`SHA-256 Hash for "${inputString}":`, hash);
    return hash;
}

// Викличте для вашого логіна та пароля
// getMyHash('ваш_логін');
// getMyHash('ваш_пароль');
```

Після отримання хешів, оновіть `config.js` відповідними значеннями.

## Структура проекту

*   `main.html`: Основний файл програми з картою та 3D-моделями.
*   `admin.html`: Файл адміністративної панелі.
*   `config.js`: Файл конфігурації, що містить налаштування програми та дані автентифікації.
*   `models/`: Директорія для 3D-моделей (наприклад, `Town-Gradient.glb`).
